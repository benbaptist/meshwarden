we should rethink the UI (and backend concepts if neccesary) here

- 'nodes' tab should not exist; it should be an upstream, main thing that can be 'switched' to that changes all downstream UI elements. as if it were switching user accounts on an email service, for example. everything downstream (chat lists, etc.) all depends on the connected node.

- 'Groups' tab probably shouldn't exist either; ideally, it would just be better integrated into the Contacts page for better organization. 

- 'chat' tab is actually redundant too. it should just intuitively occur when I click on a node in the contacts tab. 

- all of this really boils down to the actual heart of the matter - the contacts tab - needing to be better. that's how you see all discovered contacts, how you get into chats (and see unread chats, etc.), as well as just seeing at-a-glance contact deets (with a good focus on mobile-first usability but good expansion on wider tablet or desktop viewports). in addition to that, here's some other notes for the contacts tab
    - Change sorting by clicking on various columns
    - shorthand for actions on wide-enough viewports

- 'Main' tab is kinda redundant; let's do the typical mesh thing that a lot of mesh-related apps (meshcore or tastic) do and just make the default tab a map, using a nice open source-friednly mapping solution, showcasing node locations, etc.
